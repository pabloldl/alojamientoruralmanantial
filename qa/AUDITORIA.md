# Auditoría de originalidad · 23/10/2026

## Alcance y método

Antes de implementar se inspeccionaron las estructuras HTML y reglas CSS/JS de las **20 webs anteriores accesibles** en el workspace. Se extrajeron encabezados, navegación, familias tipográficas, geometría, grids, contacto, footer, hover, keyframes, observadores y breakpoints. Se amplió la lectura de los scripts de las tres webs rurales prioritarias. La comparación anterior es de código; no se ejecutaron ni se capturaron visualmente los 20 proyectos. Las capturas de esta carpeta corresponden exclusivamente al proyecto nuevo.

## Revisión de los 18 aspectos solicitados

| Aspecto | Decisión aplicada a Manantial |
| --- | --- |
| Arquitectura | Superficie continua con portada escultórica, estudios de textura, vacío tipográfico, cauce, cartografía abstracta y corriente de contacto. Sin módulos de servicios ni galería. |
| Orden | Se conserva el recorrido solicitado, enlazando las experiencias mediante curvas de superficie, proporciones y trazos, sin reproducir las secciones comerciales de los proyectos rurales. |
| Menús | Identidad separada y pequeña superficie flotante de dos accesos; no hay header convencional, rail lateral ni navegación inferior. |
| Navegación móvil | La superficie se reduce a «Hablemos» y «Llamar», sin botón hamburguesa ni overlay. Ubicación accesible en el recorrido y desde contacto. |
| Botones | Llamada y Maps en superficies de curvatura asimétrica; copiar se representa mediante contornos líquidos dobles. |
| Formas | Radios elípticos desiguales y morph de contorno; no se emplean los botones rectangulares, industriales o de etiquetas anteriores. |
| Tipografías | Syne, Petrona y Commissioner; ninguna encontrada en las webs auditadas. |
| Títulos | Nombre en tres líneas con línea central de menor escala; titulares amplios alternados con serif ligera, sin numeración. |
| Párrafos | Copia breve y factual, con notas ilustrativas junto a imágenes. No se copian descripciones ni promesas comerciales. |
| Espacios | Amplias pausas, desplazamientos laterales, elementos a escala distinta y cambios de superficie sin tarjetas. |
| Fotografías | Cuatro archivos nuevos, naturales y con licencia; no se reutilizan las fotos de las otras webs ni se atribuyen a la propiedad. |
| Galerías | No existe grid convencional, carrusel, filtro ni lightbox. Los estudios fotográficos forman parte de la composición. |
| Iconografía | Símbolo propio de corrientes, curvas de dirección y contornos mínimos. No hay librería de iconos ni emojis. |
| Animaciones | Entrada de máscara elíptica, revelado por recorte y rotaciones puntuales de ondas. Sin fade-up repetido ni movimiento constante. |
| Hover | Cambios de curvatura, contracción de subrayado y desplazamiento angular de contornos. |
| Contacto | Número sobre tres corrientes SVG en superficie clara; no se usa tarjeta, carta, placa, teléfono de dispositivo ni bloque oscuro. |
| Footer | Firma pequeña de corrientes dentro de la última superficie, identidad de dos líneas y datos mínimos. |
| Responsive | Recomposición específica bajo 650 px: tipografía antes de fotografía, secuencia vertical de texturas, sello reducido, manantial en eje vertical y navegación abreviada. |

## Límites de la afirmación de originalidad

Se creó el HTML/CSS de este proyecto desde cero sin copiar componentes visuales de las otras carpetas. No se promete una diferencia absoluta frente a todas las webs existentes: enlaces nativos, patrones de accesibilidad y mecanismos estándar como IntersectionObserver o Clipboard API son técnicas compartidas. El resultado tiene un sistema visual propio frente al conjunto inspeccionado.
